# Локальная цепочка блоков на Flask

Учебное Flask-приложение создаёт цепочку JSON-блоков, показывает проверку её целостности и демонстрирует proof of work. Данные хранятся локально в [`blocks/`](blocks/).

## Запуск

```bash
python -m pip install -r requirements.txt
python server.py
```

Откройте `http://127.0.0.1:5000/`.
